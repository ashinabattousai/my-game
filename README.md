# My Game — Vocabulary Battle

一个用 Unity UGUI 制作的单词练习小游戏：玩家根据题干输入答案，答对攻击怪物，答错扣血并记录到错题本。

## 当前内容

- **首页**：进入模式选择或打开错题本。
- **模式选择**：支持日语（JP）和英语（EN）词库标签。
- **战斗场景**：输入答案、计算分数/连击/血量/击杀数，并按击杀数生成普通怪或 Boss。
- **错题本**：答错的题会自动保存，可查看详情或标记掌握。
- **运行时 UI 皮肤**：无需手动给每个场景补图，启动后自动添加渐变背景、星光、面板/按钮/输入框样式，以及像素风角色/怪物/书本插图。

## 词库格式

词库位于 `Assets/Data/words.json`，每条数据包含：

```json
{
  "prompt": "中文题干",
  "answers": ["可接受答案1", "可接受答案2"],
  "lang": "jp"
}
```

`lang` 建议使用：

- `jp`：日语模式
- `en`：英语模式
